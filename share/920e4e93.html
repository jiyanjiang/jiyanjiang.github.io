当理论计算机科学回响，预训练悄然重塑格局：2019年arXiv计算机科学进展侧写

这是 arXiv 领域二分升级之后的第一份计算机科学分版年度侧写。此前的年份里，计算机科学与物理学、数学共用同一个语料空间，深度学习的热潮淹没了许多与之无关的学科信号。2019年，当镜头只对准主分类标为 cs.* 的预印本时，浮现出来的不再是一幅深度学习单极膨胀的图画，而是一组三条线索交织的菱形格局：一边是算法复杂度与下界（lower bound）等理论计算机科学术语的集体爬升，另一边是大型预训练模型（pre trained）与微调（fine tuning）这对新范式在加速度榜上留下的清晰齿痕，中间地带则是图神经网络（Graph Convolutional Networks，GCNs）、对抗攻击（adversarial attacks）和多智能体强化学习（multi-agent reinforcement learning）等热点方向在已有高地上继续伸展。这些信号共同告诉我们，2019年的计算机科学在 arXiv 上进入了一个“平台期的结构分化”阶段。

承接2018年深度学习工具化的浓墨重彩，2019年的速度榜上仍然弥漫着深度学习的气息，但它们已经褪去了前几年那种“横扫一切”的新锐劲头。在共现加速度（pair_accel）榜单上，卷积神经网络（convolutional network(s)）与深度学习（deep learning）的搭配加速度为负万分之二点九，是退潮榜的榜首；卷积神经网络与目标检测（object detection）的搭配也跌了万分之一点六，计算机视觉（computer vision）与卷积神经网络的共现加速度同样为负。这并非意味着这些技术被抛弃了，而是2018年曾经爆发式增长的描述性词对开始回落到一个更为常态的水平——换句话说，卷积神经网络做目标检测、深度学习做计算机视觉，已经从需要大书特书的“方法贡献”变成了默认配置，摘要不再反复念叨这句话。同时，deep learning×neural network(s) 这对最核心的兄弟组合虽然速度值仍有提升，但加速度也转为了负值。这表明，深度学习在 arXiv cs 库内的词频占比已经接近饱和，研究者不再需要每篇论文都以“deep learning”为旗号来吸引眼球，而是直接进入具体任务和方法细节。

正是在这种用语饱和的背景板上，两类此前被深度学习洪流遮蔽的语词群体开始显露出来。第一类是理论计算机科学中关于复杂度与下界的经典语词。在共现加速度前十名中，出现了多个看似与深度学习无关的组合：lower bound(s)×upper bound(s) 加速度达到亿分之一百四十，communication complexity×lower bound(s) 亿分之一百，np hard×polynomial time 亿分之一百，best known×upper bound(s) 亿分之九十。这些词的语法搭配透出一种非常“老派”的理论气质。它们不是那种围绕某个新数据集展开的实验报告用语，而是证明式论文的骨架。

以通信复杂度（communication complexity）与下界的共现为例，一篇题为“图稀疏化子在消息传递模型中的研究”（1911.05991）的预印本在摘要里提到“在消息传递模型中，我们证明了通信复杂度的下界，并给出了几乎匹配的上界”。另一篇关于“aBc 问题与赤道抽样 Rényi 散度”的工作（1912.11275）同样嵌入了这对术语，其摘要指出“我们在通信复杂度模型中研究了近似问题”。这些论文讨论的不是 GPU 耗时、也不是在 ImageNet 上提了几个点，而是多玩家通信模型中函数计算所需的最低通信量。也就是说，2019 年 arXiv 计算机科学中，有一类扎实的理论推演在默默地推动着“下界（lower bound）”与“上界（upper bound）”这对概念反复共现。NP 难（np hard）与多项式时间（polynomial time）的配对也不断冒头。一篇研究“最大边着色问题的改进近似算法”（1910.11753）的预印本摘要里写道“该问题是 NP 难的，我们给出了一个多项式时间的近似方案”。另一篇关于“承诺 SAT 在非布尔域上的复杂度”（1911.09065）的论文则直指“三分 SAT 是 NP 难的，而二分 SAT 可在多项式时间内解决”。这类表述在 2018 年混合版综述中几乎不会作为独立主线出现，因为当年被深度学习的热词压得密不透风。2019 年的 cs 分版数据给了它们本该有的露脸机会。

第二类突然清晰起来的语词群体，正是 2019 年深度学习内部最核心的结构性迁移——从“从头训练”到“预训练加微调”的范式转变。在共现加速度榜上，large scale×pre trained 以亿分之百的加速度排在前列，fine tuning×pre trained 亿分之六十，pre trained×transfer learning（迁移学习）也在加速度榜上录得正值。速度榜中，fine tuning×pre trained 的速度值达到亿分之一百三十，是全年最显著的新兴词对之一。这组信号的含义很直白：研究者在 2019 年不再只说“我们训练了一个深度神经网络”，而越来越多地说“我们拿一个大规模预训练好的模型，然后针对下游任务做微调”。

很多实例直接印证了这股风气。一篇题为“利用预训练词向量和文本分类器进行单语对齐更新”的预印本（1910.06241）在摘要中明确写道“本文关注如何将预训练模型适应于新的文本数据，通过微调来实现”。另一篇关于“将常识知识融入语言表示模型”的论文（1908.06725）则提出了一种简单方法：“对齐、掩码并选择——一种将常识知识融入预训练语言表示模型的简单方法”，文中多次出现 pre trained 和 fine tuning 的组合。这种预训练加微调的套路不仅在自然语言处理（NLP）中盛行，在计算机视觉领域同样铺开。一篇发表于 1912 号的预印本（1912.07971）题为“条件生成卷积网络用于基于样例的纹理合成”，其摘要提到“我们基于预训练的卷积神经网络来合成纹理图像”。还有一篇关于“多模态分割中缺失 MR 序列的处理”（1909.11464）也用了 pre trained fusion networks。可以毫不夸张地说，2019 年 arXiv 计算机科学的关键叙事之一，就是预训练模型作为基础组件被“插拔式”使用的习惯正在固化。这与 2018 年综述中描述的深度学习工具化一脉相承，但往前迈了一大步：2018 年的工具化更多是“用深度学习做某事”，而 2019 年的工具化则进阶为“用预训练模型微调做某事”。深度学习本身不再被强调，被强调的是预训练这个源头。

紧挨着预训练浪潮的，是图神经网络（GCNs）的群体性涌现。graph convolutional networks gcns 这个固定短语在速度榜上位列前茅，速度值亿分之一百三十。大量工作围绕 GCN 展开：一篇关于“图卷积网络的批量虚拟对抗训练”的预印本（1902.09192）摘要中写道“我们提出批量虚拟对抗训练，用于正则化图卷积网络”。另一篇关注“图卷积网络面对对抗攻击的鲁棒性”的论文（1911.04429）则试图“通过图谱域防御增强 GCN 的鲁棒性”。还有一篇讨论“图卷积网络与高维降维相遇”（1911.02928）的工作，把 GCN 与经典降维技术摆在了一起。这些预印本暴露出一个事实：图结构数据的表示学习在 2019 年已经成为机器学习内部一个辨识度极高的子方向，其热度不再是星星点点，而是形成了自己的术语聚落。

与 GCN 齐头并进的还有对抗攻击（adversarial attacks）与深度神经网络的深度纠缠。adversarial attacks×neural network(s) 的速度值为亿分之一百二十，adversarial attacks×deep neural networks 也达到亿分之百。这个主题的论文普遍在摘要中表现出一种紧张感：“深度神经网络非常脆弱，我们试图理解并防御”。例如一篇题为“对抗攻击下时间序列入侵检测”的预印本（1911.04278）警告说“神经网络很容易受到对抗样本的影响，攻击者可以隐藏其攻击”。另一篇研究“对抗样本的可迁移性”的论文（1907.10823）则试图“生成更具迁移性的对抗样本来误导黑箱模型”。2019 年被一些研究者称为“对抗鲁棒性之年”，在 arXiv 上，这个称呼至少在术语热度上有着确凿的证据。

社交网络分析（social network(s)）在 2019 年也达到一个速度与加速度的共振点。real world×social network(s) 的加速度在共现加速度榜上高居第一，达到亿分之一百九十，这意味着该词对在 2018 到 2019 年间出现了急剧的浓度爬升。influence maximization×social network(s) 加速度亿分之八十，information diffusion×social network(s) 加速度亿分之七十。这些组合背后是计算机科学与社会科学交叉地带的一段活跃期。一篇关于“俄罗斯巨魔在推特上使用图像进行信息战”的预印本（1901.05997）对真实世界社交网络中的信息操控做了大规模实证分析。另一篇题为“群体公平性在影响最大化中的考量”的论文（1903.00967）提出“在社交网络中进行影响最大化时需要考虑群体公平”。还有一篇“DeepFork：在GitHub中监督预测信息扩散”的工作（1910.07999）则用深度学习方法分析社交编码平台上的信息传播模式。社交网络不再只是图论的一个应用背景，它开始与公平性、信息战、开源社区生态等宏大议题勾连在一起，形成了一组有社会科学温度的计算研究。

需要注意的是，2019 年的数据中也出现了一些“无确切学术内容”的边缘词对，例如 real world 与 shed light 的组合，或 high signal 与 noise ratio 这类无线通信中的常用语。根据综述规范，这些词对虽然反映了某些表述习惯的扩张，但我不会把它们当作计算机科学本身的热点来展开解读。

现在有必要回望一下 2018 年综述曾着重描绘的“深度学习工具化”在 2019 年走到了哪一步。上一年的描绘中，object detection（目标检测）、semantic segmentation（语义分割）和 optimization problem(s) 等任务词是深度学习下沉为日常工具的主要出口。2019 年，这些词在共现加速度退潮榜上集体出现：convolutional network(s)×semantic segmentation 加速度跌了亿分之十四，deep learning×object detection 跌了亿分之十八，deep learning×time consuming 跌了亿分之十五。这种退潮不是说这些任务不重要或者停滞了——相反，2019 年依然有大量关于语义分割和点云（point clouds）的工作，例如点云语义分割方法（1909.09287）和 RGB 与 LiDAR 融合的三维语义分割（1906.00208）——而是说，当这些任务方法已经成为标准组件时，摘要写作的语词偏好从“我们提出了一种基于卷积神经网络的语义分割方法”变成了更具体的“我们在某个基准上达到了何种性能”或“我们解决了某个子问题”。工具化到了极致，词频反而开始收敛。

另一个 2018 年完全没有预料到、2019 年却鲜明崛起的方向是多智能体强化学习（multi-agent reinforcement learning）。multi agent×reinforcement learning 的速度值达到亿分之八十，共现加速度也为正值。一篇关于“多智能体强化学习中的涌现通信”的预印本（1912.05676）专门研究了“智能体在强化学习过程中如何自发形成通信协议”。另一篇名为“Arena：一个多智能体智能的通用评估平台”的工作（1905.08085）则试图为多智能体学习提供一个标准化的测试环境。还有一篇通过协作多智能体对话模型训练的工作（1907.05507）将强化学习用于对话系统的联合训练。这些迹象表明，2019 年是一个多智能体强化学习从游戏走向更通用智能体协作的关键年份，arXiv 成为这一趋势的记载者。

在所有的语词挪移中，一个长期视角下不可忽视的符号是“https github com”这个短语在速度榜上的大范围渗透。它本身并不是一个学术术语，却成为 2019 年高质量预印本的一种标配：https github com×source code 速度值高达亿分之二十二，https github com×publicly available 亿分之十四，https github com×neural network(s) 亿分之十五。这组词对传达了计算机科学开放研究实践的深化——研究者不仅提出方法，还附上代码仓库链接，让结果可复现。一篇关于“认知知识图谱推理的 one-shot 关系学习”（1906.05489）在摘要末尾附上了代码地址。另一篇提升无监督领域自适应性能的工作（1908.09822）同样标出了“代码已公开”。这种将可复现性写入摘要的习惯，是 2019 年 arXiv 上传实践的文化印记，也是计算机科学区别于其他学科的一个务实特色。

结尾之前，必须把三条关键的观察边界郑重交还给读者。第一，覆盖面局限：2019 年并非所有计算机科学分支都习惯在 arXiv 上提交预印本。数据库、系统、硬件、人机交互等领域在 arXiv 上的覆盖率远低于机器学习和理论计算机科学。因此这篇综述更多是“2019 年 arXiv 计算机科学热点的印记”，而不是整个学科的全球进展全貌。特别地，这一年深度学习本身处于平台期，预训练、图神经网络、对抗攻击等方向在 arXiv 上更为显眼，一定程度上也放大了它们的统计信号。

第二，速度与加速度的双重源头：任何一个术语占比的抬升，既可能是因为学术界对该主题的真实研究投入增加，也可能是因为该方向的学者群体恰好在 2019 年更加密集地把论文投向 arXiv。例如，large scale×pre trained 的加速度猛增，很可能与 NLP 领域 2018 年底 BERT 出现后引发的预训练方法爆发有关，它是真热；但 lower bound(s)×upper bound(s) 的爬升，或许部分反映了一些原本主要在会议发表的理论计算机科学工作开始向 arXiv 同步投稿，这是一种投稿习惯的逐步扩散。两种效应在单年数据中无法分离，读者需对任何“热度爆发”都保持一份统计上的谨慎。

第三，观察窗口的不足：本文只基于 2017（基线）、2018（上年）和 2019（当年）这三年的语词快照。要判断一个趋势究竟是长期范式迁移还是短期波动，必须拉长到五到十年的数据才能下结论。例如预训练加微调的兴起是否会在未来几年成为支配性范式，图神经网络是否会从爆发走向平稳，社交网络分析中的公平性议题能否持续加剧，都需要后续年份的验证。2019 年只是计算机科学 arXiv 分版观察的第一站，它提供了一个清晰但受限于窗口的起点。

合上数据，2019 年 arXiv 计算机科学的语词地图呈现的是一幅分工愈发明确的图景。理论家们沉入通信复杂度和下界的证明中，实践者们忙着把预训练 Transformer 塞进各类任务的骨干里，社交网络分析师开始用图神经网络测量真实世界的信息流动，而那个曾经占据一切版面的“深度学习”大词，则终于退后半步，变成了其他故事中一个无需反复强调的前提。
