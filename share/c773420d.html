当数据自己开口说话：2019 年 arXiv 基础科学库的纯物理信号

2019 年，arXiv 的论文分类体系经历了一次静默却意义深远的内部划界。此前，物理学与计算机科学在同一个统计池中共享语词空间，一篇讲深度学习的医学图像分割论文和一篇分析 LHC 13 TeV 质子对撞积分亮度的粒子物理快报，在词频计数里被不加区分地掺在一起。2019 年基础科学库的建立，把主提交分类非 cs.* 的预印本精确地剥离出来——于是我们第一次获得了一幅未被深度学习术语淹没的、纯正的基础科学语词地图。在这幅地图上，高能物理、凝聚态物理、天体物理和规范场论的信号终于摆脱了卷积神经网络和损失函数这些庞大语词群的遮蔽，露出了它们原本的轮廓。

这幅地图告诉我们什么呢？2019 年不是 2016 年，没有引力波那样改写教科书的发现性宣告。也不是 2017 年，没有「深度学习全面登顶 arXiv」那样剧烈的术语版图重构。2019 年更像是一段沉淀与蓄力的中继期：LHC 的 Run 2 数据产出进入了稳健的积分亮度累积阶段，LIGO 和 Virgo 的引力波探测从单事件发现转向多事件统计，凝聚态物理在磁性相图和拓扑材料两个方向上各自深耕，而四维规范场论的语词加速则暗示着理论物理在某个幽深处正酝酿着新的数学结构。当然，深度学习的语词仍然在基础科学库的边缘地带留下了一些余响——它并未消失，只是不再占据舞台中央了。

这篇文章将围绕数据本身所浮现的五条主线展开。每一条主线都不是人为预设的框架，而是从词频速度、共现加速度和退潮信号中自然浮现的语词群落。我们会看到：大型强子对撞机（Large Hadron Collider, LHC）上逆飞靶（inverse femtobarns）和积分亮度（integrated luminosity）这对搭档如何在加速榜上猛然跃升；低质量中子星（low mass×neutron star(s)）如何在引力波天文台多事件时代成为新的焦点；磁场与相图（magnetic field(s)×phase diagram）如何在凝聚态物理摘要中密织成网；四维规范场论（four dimensional×gauge theory(ies)）为何在加速度上独树一帜；以及自旋轨道耦合与单晶衍射（electronic structure×spin orbit coupling、ray diffraction×single crystal(s)）如何在材料科学语词群中加速上行。

LHC Run 2：积分亮度语词群中的稳健产出节律

在高能物理的摘要写作传统中，有一类语句堪称标配——它们开篇就会宣告本文所使用的数据量，其语法几乎是一种固定的仪式。2019 年基础科学共现加速榜上，排名第一的组合赫然写着「inverse femtobarns×proton collisions」（逆飞靶×质子对撞），加速度值领先全榜。紧随其后的第二名是「integrated luminosity×inverse femtobarns」（积分亮度×逆飞靶），同样录得高值。这两个信号揭示了一个事实：LHC 的 Run 2 数据产出在 2019 年持续释放，质子-质子对撞在 13 TeV 质心能量下累积的积分亮度已经大到让逆飞靶这个单位变成了高能物理摘要中的常规货币。逆飞靶的物理含义是每个横截面积上穿过的粒子数——一个逆飞靶对应每平方厘米穿过约 10^41 个粒子——它是衡量加速器数据产出的核心刻度。当这个词在高能物理论文的摘要中以高密度集体出现，说明实验合作组正处于密集的物理分析释放期。

具体来看，一篇发表在 2019 年 12 月的 CMS 实验论文（1912.02508）在摘要中讨论「在 LHC 的质子-铅核对撞中通过双部分子散射产生 W 玻色子加双喷注的截面」。另一篇同样来自 CMS 的 Z 玻色子微分截面测量（1909.04133）写道「所分析的数据由 CMS 探测器在 2016 年于 13 TeV 质子-质子对撞中收集」。还有一篇 ATLAS 探测器搜索喷注对质量分布中新共振态的工作（1910.08447），其摘要第一句就宣告「使用了 2015 至 2018 年间在 13 TeV 质子-质子对撞中记录的 139 逆飞靶数据」。这些摘要的共同特点是把逆飞靶和质子对撞这两个词紧紧绑在同一个句子里——这是 LHC 实验物理学家在 2019 年养成的写作肌肉记忆。

另一件值得留意的事情是共现加速退潮榜上出现了这样的组合：「integrated luminosity×upper limit(s)」（积分亮度×上限），加速度大幅为负。这组数据意味着什么？2017 到 2018 年间，大量 LHC 的超越标准模型新物理搜索论文习惯性地把「积分亮度」和「未观察到显著超出因而设定上限」放在摘要中配对出现。到了 2019 年，这种「搜索－上限」套路的语词密度明显降低了。一个合理的解释是：Run 2 物理分析的重心，正在从「以排除新物理参数空间为目的的搜索型论文」向「以精密测量标准模型参数为目的的测量型论文」转移。当重心转向精密测量，摘要中出现的不再是「上限」这个否定性词汇，而是「截面」「分支比」「耦合强度」这些肯定性物理量。这当然不是说新物理搜索停止了——事实上 CMS 仍在搜索压缩质量谱超对称粒子（1910.01185）以及暗光子与希格斯玻色子联合产生（1908.02699）——而是说 LHC 物理产出的整体语词景观在 2019 年变得更均衡、更多样、更偏精密测量。对 arXiv 基础科学库而言，这些信号的共同含义是：Run 2 的黄金数据仍在持续被消化，但其语言痕迹已经从一种集中的、爆发式的「宣告模式」转变为一种分散的、稳态的「分析模式」。

双中子星之后：引力波时代的常规化与低质量中子星的语词升温

如果把 2017 年 8 月双中子星并合事件 GW170817 以及连带发现的千新星（kilonova）电磁对应体看作引力波多信使天文学的诞生时刻，那么 2019 年就是这个婴孩开始学步的年份。2019 年基础科学共现加速榜上，排名第三的组合是「low mass×neutron star(s)」（低质量×中子星），其加速度与逆飞靶系列组合处于同一个量级。

低质量中子星在 2019 年突然成为加速上升的语词组合，背后是 LIGO/Virgo 引力波天文台持续观测带来的效应。在 GW170817 事件中，双中子星并合的总质量相对较低——两颗星各自大约 1.2 到 1.6 个太阳质量——这个特征促使天体物理学家重新审视低质量中子星的形成渠道和状态方程（equation of state, EoS）约束。2019 年 arXiv 基础科学库中，有多篇预印本正是沿着这个方向展开的。一篇通过贝叶斯方法结合天体物理和引力波观测约束中子星宏观可观测量的论文（1902.05078），摘要中明确出现了「低质量中子星」和「状态方程」的搭配。另一篇探讨磁致热中子星山发射引力波的预印本（1910.04453），在摘要中点明「许多低质量 X 射线双星系统包含快速旋转的中子星」——一句话同时嵌入了低质量和中子星。还有一篇以精确脉冲星计时探索引力波和极端天体物理的工作（1903.08653），同样在摘要中激活了这对组合。

与此同时，「neutron star(s)×tidal deformability」（中子星×潮汐形变能力）在速度榜上占据显要位置。潮汐形变能力描述的是中子星在另一颗致密天体引潮力作用下发生形变的难易程度——形变越大，潮汐形变参数就越大，中子星内部的物质就越「软」。GW170817 的引力波信号中包含了两颗中子星各自的潮汐形变信息，这为反向推导核物质在数倍核饱和密度下的状态方程开辟了前所未有的窗口。一篇题为「利用监督机器学习从双子星性质中提取核物质状态方程」的预印本（1910.05554），在摘要中以中子星和潮汐形变能力的搭配开场。另一篇分析超流物质对中子星潮汐响应影响的论文（1908.04235），同样嵌入了这对术语。引力波从中子星的并合波形中提取状态方程线索的工作，在 2019 年的 arXiv 基础科学库中已经形成了一股稳定的语词水流——它不是 2017 年那种爆炸性事件驱动的洪峰，而是事件沉淀为常规研究领域后持续涌流的暗河。

值得注意的是，中子星语词还与「radio emission」（射电辐射）在共现加速榜上取得显著位置——中子星×射电辐射的组合在 2019 年获得了加速。一篇利用广义相对论解释脉冲星射电辐射几何结构的论文（1909.06212）在摘要中使用了这对组合。一篇讨论重复性快速射电暴（fast radio burst, FRB）频谱中高低频漂移现象——并将其归因于中子星磁层中急剧变化的等离子体性质的预印本（1908.07313）也激活了中子星和射电辐射的共现。还有一篇对 LIGO/Virgo 事件 S190814bv（很可能为中子星-黑洞并合）进行射电对应体搜寻的工作（1910.13647）同样进入了这个语词群落。信号很清晰：引力波天文学在多事件时代，正在与传统的电磁波天文学——射电、X 射线、伽马射线——深度融合，中子星在这幅多信使拼图里既是引力波源也是电磁波源，这种双重身份使得它在 2019 年的基础科学语词图谱中同时被高能和天体两大阵营密集引用。

凝聚态磁性：相图、基态与低温下的长程秩序

如果要在 2019 年 arXiv 基础科学库的凝聚态物理信号中找一条最强的主线，那毫无疑问是磁性——更准确地说，是磁场与相图（phase diagram）的组合，以及磁场与基态（ground state(s)）的组合。这些组合在共现加速榜上占据了一个密集的语词集群，磁场似乎成了 2019 年凝聚态物理摘要中最繁忙的形容词接口。

「magnetic field(s)×phase diagram」（磁场×相图）在共现加速榜上以显赫的加速度排名前列。「ground state(s)×magnetic field(s)」（基态×磁场）紧随其后。同时进入加速度榜的还有「long range×low temperature(s)」（长程序×低温）、「exchange interactions×ground state(s)」（交换相互作用×基态）以及「low temperature(s)×single crystal(s)」（低温×单晶）。这些术语共同织成了一张典型的凝聚态磁性研究语词网络：在低温下、在单晶样品上、施加强磁场、扫描相图、寻找基态、测量交换相互作用——这几乎是强关联电子系统磁性研究的标准实验叙事程序。

具体来看，一篇以超声测量手段探索立方 PrNi₂Cd₂₀ 单晶在极低温下（0.02 K）四极矩磁化率和磁相图的预印本（1911.11914），在摘要中集齐了「磁场」「相图」「基态」「低温」「单晶」五个关键词中的四个。一篇利用磁化率、比热、介电常数、热释电电流和中子衍射多手段表征三棱格子多铁性化合物 α-NaFeO₂ 的磁电相图的研究（1903.05159），摘要中同时出现了磁场与相图的组合以及磁场与单晶的组合。还有一篇以磁场角度为调控参量、测量准 Kagome 近藤格 CeRhSn 的比热、磁卡效应和磁化强度的工作（1904.08663），在摘要里嵌入了基态与磁场的共现。

低温这一维度在 2019 年的磁性与基态研究中扮演了一个特别的角色。数据中「low temperature(s)×single crystal(s)」（低温×单晶）组合的加速度上行，意味着越来越多的凝聚态物性测量是在精心制备的单晶样品上、在极端低温条件下完成的。典型的例子如通过输运和热学测量研究三角格子量子自旋液体候选材料 1T-TaS₂ 中淬灭无序效应的论文（1909.00583），在研究反常热导率时明确使用了低温和热导率（thermal conductivity）的共现。又如把 Fe₁₊ᵧTe₁₋ₓSeₓ 单晶的超导临界电流推向拆对极限（depairing limit）的工作（1911.00727），摘要中低温与单晶双双出场。这些工作共同指向 2019 年凝聚态物理的一个特征：极低温强磁场下的物性测量正在进入一个对样品质量和测量精度都提出极高要求的精密阶段。

另一个值得单独点出的凝聚态词汇是「ground state(s)×Mott insulator」（基态×莫特绝缘体），同样在加速度榜上录得可观的表现。一篇从微观角度研究莫特绝缘体中掺杂孔洞的自旋-电荷自由度耦合——即自旋子（spinon）和荷子（chargon）理论的论文（1901.01113）就嵌入了这个组合。另一篇用深度学习方法逼近密度泛函理论中 Hohenberg-Kohn 映射——即从电子密度到基态多体波函数的映射关系的预印本（1911.03580），也触及了 Mott 绝缘体基态的深层问题。加上一篇对玻色莫特绝缘体动量空间中双体和三体关联的实验研究（1904.10995），我们看到的是凝聚态物理在 2019 年依然把「关联电子体系的基态本质」作为核心追问之一——磁性、相图、低温、单晶、交换相互作用这些工具性的物理概念，环绕着这个核心追问构筑起紧凑的话语群落。

数学物理的幽微之处：四维规范场论的语词加速

在 2019 年基础科学共现加速榜的中段，出现了一个在高能实验和凝聚态磁性的喧嚣中略显安静、却绝对不能忽视的组合：「four dimensional×gauge theory(ies)」（四维×规范场论）。

四维规范场论是理论物理和数学物理的一个深水区。我们的宇宙时空在宏观上是四维的（三维空间加一维时间），而标准模型本身就是一个四维规范场论——只不过它是一个特定规范群 SU(3)×SU(2)×U(1) 的具体实例。理论物理学家问的是更大胆的问题：在所有可能的四维规范场论中，哪些是自洽的？它们的共形行为、对偶性（duality）、反常消除和相结构如何一般性地刻画？这些问题在 2019 年的 arXiv 基础科学库中留下了清晰的语词记号。

一篇名为「在强相互作用量子场论中共形行为的研究」的博士论文（1911.00442），其摘要明确将四维规范场论作为其非微扰数值分析的核心舞台。它强调的是「共形窗口」——也就是在规范耦合常数从红外走到紫外的过程中，理论可以保持近似共形不变性的参数区间——这是当今强耦合规范场论非微扰研究的枢纽概念。另一篇从散射方程推导单圈杨-米尔斯被积函数的工作（1910.03602），在摘要里激活了四维与规范场论的组合。还有一篇探讨反常 U(1) 规范理论在紫外完备性问题——即所谓的「沼泽地猜疑」（Swampland Conjectures）——的预印本（1912.10054），同样落在这对组合的语词网络之中。这篇论文追问的是：一个低能有效的四维规范场论，在什么条件下可以被合法地嵌入量子引力理论？如果无法嵌入，它就会被划入「沼泽地」——那些看似自洽的低能理论实际上无法在紫外完备的量子引力中实现的区域。

一位在 2019 年基础科学 arXiv 上出场率不低的主角是「qq-characters」——这不是一个语词对，但它是四维规范场论语词群的一个重要附件。一篇题为「A note on chiral trace relations from qq-characters」的论文（1910.10864）研究的是四维 N=2 超对称规范场论中手征算符真空期望值之间的精确关系。这类工作属于用数学上精密的局域化技术、将四维规范场论的某些可观测量化为可严格计算的矩阵模型积分的传统——它虽然安静，但在 2019 年的加速度信号中稳稳地撑起了四维规范场论这个语词组合的热度。

值得强调的是，四维规范场论这个信号在 2019 年的基础科学库中出现，与 2018 混合版综述中该术语几乎不可见的状态形成了鲜明对照——这不一定是该领域本身的热度发生了跃升，而更可能是因为 2018 年这个术语的语词空间被深度学习相关词汇严重挤占了。当 2019 年基础科学库把 cs.* 分类精确剥离之后，理论物理的专业术语才有机会在语词统计中显影。这本身就是一个警示：基础科学分版的信号清晰度，在很大程度上来自计算机科学术语的移除，而非物理本身发生了突变。

自旋轨道耦合与单晶衍射：材料科学语词群的并行上行

2019 年基础科学共现加速榜上还有两条并肩而行的信号线：一条是「electronic structure×spin orbit coupling」（电子结构×自旋轨道耦合），另一条是「ray diffraction×single crystal(s)」（X 射线衍射×单晶）。

先看自旋轨道耦合这条线。自旋轨道耦合是电子自旋与其绕核轨道运动之间的相对论性相互作用——在重元素中它很强，对固体的电子能带结构产生根本性的重塑，从而催生拓扑绝缘体、外尔（Weyl）半金属、伊辛超导体等拓扑物相的能带条件。到了 2019 年，研究者已经不再满足于仅仅报道材料中有自旋轨道耦合，而是开始精密地拆解「电子结构」在自旋轨道耦合作用下究竟长成什么样子——包括轨道成分、自旋纹理、能带反转的细节。一篇利用八带 k·p 模型研究全壳超导-半导体纳米线（InAs/Al 混合结构）中自旋轨道耦合和拓扑相空间的论文（1901.11005），在摘要中使用了电子结构与自旋轨道耦合的典型搭配。一篇探论非有心立方晶体结构 BaPtP 中电子性质的工作（1911.02231）也激活了这个组合。还有一篇将 Al⁺ 离子浸入超冷铷和锶原子中、研究其相互作用和电荷转移动力学的理论工作（1908.07492），同样在摘要里记录了对自旋轨道耦合的考量。这些工作的共同特征是：自旋轨道耦合不再是标题里的光鲜概念，而是电子结构计算中必须精细计入的物理项。

与自旋轨道耦合几乎并行加速的，是 X 射线衍射与单晶的组合。单晶是凝聚态物理和材料科学实验中最重要的样品形态——与多晶粉末相比，单晶能提供各向异性的物性信息并消除晶界干扰；而 X 射线衍射是确定晶体结构和相变最经典也最可靠的手段。在 2019 年 arXiv 基础科学库的语词信号中，这对经典实验搭档展示了强劲的加速度。一篇研究在兆巴高压下强自旋轨道耦合绝缘体 Sr₂IrO₄ 反常规避金属化的预印本（1910.10291），摘要中使用了高压、X 射线衍射和单晶。一篇通过高分辨率单晶 X 射线衍射重新审视 (Mg,Fe)O 在高压下自旋态交叉的论文（1912.10414），也是 X 射线衍射与单晶组合的典型案例。还有一篇报告浮区法生长钡锶取代的汉紫单晶 Ba₀.₉Sr₀.₁CuSi₂O₆ 以供中子散射研究的工作（1907.00722），在摘要中把 X 射线衍射、单晶和中子衍射全部串在了一起——这是凝聚态实验的标准配置：用 X 射线衍射确定结构，用中子散射看磁序，一切工作都建立在高质量单晶的基础上。

这两条并行线——自旋轨道耦合与电子结构、X 射线衍射与单晶——合在一起，描绘出 2019 年材料科学基础研究的一幅典型工作图景：实验室里生长出高质量单晶，用 X 射线衍射确定晶体结构和对称性，然后结合角分辨光电子能谱、量子振荡或第一性原理计算，厘清自旋轨道耦合如何形塑该材料的电子能带结构和拓扑性质。这幅图景不是 2019 年才诞生的，但它在 2019 年的 arXiv 基础科学语词信号中获得了年度性的加速印证。

天平的另一端：机器学习语词群的退潮与残留

写过 2018 年混合版综述的人，一定还记得那一年的词频海底地层是怎样的——深度学习、神经网络、机器学习几乎覆盖了从榜首到中段的所有加速位次。2019 年基础科学库建立之后，这些词汇被分到了 cs.* 库中。但这个分库并不是一把将 cs.* 与物理数学切得干干净净的手术刀：许多物理学家和数学家在自己的基础科学论文中仍然会使用深度学习方法，只不过使用的方式已经明显偏向于工具化，不再占据摘要的核心叙事位置。

在 2019 年基础科学库的速度榜中，深度学习相关组合仍然存在——「deep learning×neural network(s)」（深度学习×神经网络）在速度榜上位列前茅，但其身影已经比 2018 年混合版中的密度大幅稀释。与此同时，在加速度榜上，深度学习与某些应用场景的组合——如「deep learning×image quality」（深度学习×图像质量）、「deep learning×ground truth」（深度学习×地面真值）——仍然保持着正的加速度。但这些信号在基础科学库中已经不是主流底色，而更像是少数跨学科论文留下来的词语余韵。

比如一篇利用神经网络进行引力波贝叶斯后验推断的论文（1909.05966），摘要中出现了深度学习和真实时间的共现——但它的核心物理目标显然是提升引力波参数估计的效率。又比如一篇把神经网络量子态用于两维阻挫 J₁-J₂ 模型基态的研究（1903.06713），摘要中同时嵌入了量子态、波函数和神经网络——这本质是一篇强关联物理的论文，神经网络在这里的角色是变分拟设（variational ansatz），而不是一个独立的研究对象。这些例子表明，2019 年基础科学库中残留的深度学习语词，已经显示出强烈的工具属性：它们不再是摘要叙事的主体，而是作为物理或数学问题解决方案中的一个技术组件低调出场。这与 2018 年混合版综述中描绘的「深度学习工具化渗透」叙事是一脉相承的，只不过在 2019 年的分版数据中，这种渗透的可见度已经被库边界大幅削减了。

在语词退潮的赛道上，有一个值得留意的方向：客观函数与优化问题的组合（objective function×optimization problem(s)）在加速度上大幅退潮；机器学习和优化问题的组合同样进入加速退潮榜。这些组合在 2017 到 2018 年间，曾随着深度学习的热潮而在 arXiv 语词空间中密集膨胀。2019 年它们在基础科学库中的退潮，既反映了 cs.* 分库后这些术语的核心地带被剥走，也印证了物理学和数学本体领域对「模型优化方法论」的摘要写作兴趣正在降温。物理学家的摘要回到了磁场、相图、基态和规范场论——这些他们本该谈论的东西。

还有一些散落的加速信号值得一瞥。暗物质与早期宇宙（dark matter×early universe）在速度榜上录得正的加速度——一篇在标量场论框架下讨论动态宇宙学常数（所谓「跑动真空模型」）的论文（1901.06638）和一篇探讨修正引力理论中宇宙学常数演化的预印本（1905.09933），都使用了这对共现词。星系形成与高红移（galaxy formation×high redshift）同样加速上行——一篇用流体动力学模拟在 f(R) 修正引力模型中追踪星系形成的论文（1907.02977），以及一篇将细致的尘埃模型植入半解析星系形成模型 L-Galaxies 的工作（1904.02196），为这个组合贡献了质量不错的实例。至于「gamma ray emission×upper limit(s)」（伽马射线辐射×上限），则体现了高能天体物理领域中用费米大视场望远镜（Fermi-LAT）和地面切伦科夫望远镜阵列对宇宙线源、暗物质湮灭信号进行持续排除性搜索的稳定产出节律——一篇分析超新星 1987A 区域近期 GeV 增亮现象的论文（1903.03045）以及一篇对核塌缩超新星甚高能伽马射线辐射设定上限的 H.E.S.S. 合作组工作（1904.10526），都在摘要中押上了伽马射线辐射和上限这两个词。

三条边界的坦承

任何基于单年 arXiv 语词数据的综述，都必须在其结尾处安放边界标识。本文亦然。

第一，覆盖面的局限。基础科学库以物理系的 hep、astro、cond-mat、quant-ph、nucl、gr-qc 以及 math 为主提交分类构成。它所覆盖的基础科学是有学科偏向性的——化学、地球科学、生命科学领域的基础研究大部分不在这个库的视域内。因此本文所能追踪的「基础科学进展」，实际上是「arXiv 上以物理和数学为主的基础科学预印本的语词动态」。银河系天体物理的盖亚数据消化周期、LHC 的 Run 2 积分亮度累积、凝聚态磁性的低温相图研究——这些都在这个库的视野里；而 CRISPR 基因编辑的进展、大气二氧化碳浓度的跨年监测、分子动力学的力场开发——这些则不在。

第二，速度与加速度的双重身份。逆飞靶与质子对撞的组合在 2019 年加速度陡升，其中有多少是因为 LHC Run 2 数据确实在 2019 年集中释放，又有多少是因为实验合作组的预印本投稿习惯在持续向 arXiv 迁移？低质量中子星语词加速，背景究竟是引力波多事件统计确实引燃了中子星结构研究的持续升温，还是中子星物理学家群体在 GW170817 事件后的投稿密度从高峰期进入了逐年稳定增长的通道？这两条效应在单年语词数据中无法解开。一个知情的物理学读者可以利用自己的学科背景知识对信号做半定量的加权判断，但统计本身无法给出干净的分拆。

第三，长期视角的缺失。本综述的观察窗口严格限定在 2019 年与上一年 2018 年和基线年 2017 年的词频变化曲率内。一个在 2019 年加速上行的词群——比如磁场和相图的组合——究竟是一次短暂的年度热浪，还是一个持续多年的范式迁移在 2019 年恰好穿过了加速阈值？这需要连续五年、十年甚至更长时间维度的词频曲线才能回答。2019 年是 arXiv 基础科学分版的第一年，它种下了一棵坐标树，但树的年轮还需要后续年份的综述来一圈一圈加码。四年、五年后回过头来看今天写下的这些段落，可能会觉得有些判断太保守——也可能太乐观。这正是年轮书写本身的价值和局限所在。

尽管如此，2019 年 arXiv 基础科学库的语词信号仍然清晰地勾勒出了一幅令人信服的年度肖像：LHC 的积分亮度数据在物理摘要中持续释放，引力波多信使天文学在中子星语词群落中稳健扎根，凝聚态物理在极低温强磁场下精细刻画相图与基态，理论物理在四维规范场论的幽深处埋下新的数学锚点，而材料科学家则用 X 射线衍射和自旋轨道耦合计算反复叩击晶体对称性的物理后果。这些信号彼此独立却又在「基础科学」这个广阔范畴下并行不悖——这就是 2019 年的基础科学在 arXiv 上留下的语词真实，一次没有被卷积层遮蔽的物理脉动。
